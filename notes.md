## 🗓️ 3. Cronograma Detalhado Semanal

### 🧠 Semana 1: O "Gargalo" de Exatas
*   **Cálculo III:** Vetores em 3D, superfícies quádricas e Derivadas Parciais.
    *   *📺 Canal de Apoio:* Aulas do [Professor Possani na UNIVESP](https://youtube.com) ou o módulo básico do [Canal MeSalva!](https://youtube.com).
*   **Eletromagnetismo:** Força elétrica, Campo elétrico e a temida Lei de Gauss.
    *   *📺 Playlist de Apoio:* Assista às aulas de campo elétrico do canal oficial [Fisica Universitária - USP](https://www.youtube.com/playlist?list=PL1Dg4Oxxk_RIBxL2PK0ngBqWyNEfizTbw).
*   **Mecânica Geral:** Estática dos corpos rígidos, forças de momento e equilíbrio.
*   **🎯 Desafio da Semana:** Criar um script rápido em Node.js (usando apenas JavaScript puro) que calcule automaticamente o produto vetorial de dois vetores em 3D para você conferir os seus exercícios manuais de Cálculo III.

```markdown
- [ ] Resolver 10 exercícios de Derivadas Parciais no papel
- [ ] Desenhar o fluxo de linhas de um campo elétrico no caderno
- [ ] Criar o script JS para cálculo de vetores 3D
```

---

### ⚡ Semana 2: O Bloco de Hardware Análogo
*   **Circuitos Elétricos II:** Revisão brutal de números complexos aplicada a circuitos. Entender Fasores e Impedância de capacitores/indutores em Corrente Alternada (CA).
    *   *📺 Canal de Apoio:* Aulas do canal focado em engenharia elétrica [Engenharia Reversa no YouTube](https://www.youtube.com/engenhariareversa).
*   **Eletrônica II:** Física dos semicondutores. Comportamento e polarização de Diodos, Transistores BJT e MOSFET atuando como chave lógica.
*   **🎯 Desafio da Semana:** Baixar o simulador gratuito [LTspice para Windows/Mac](https://analog.com). Se quiser uma opção web mais rápida para testar diodos sem instalar nada, use o simulador interativo [Falstad Circuit Simulator](https://falstad.com). Monte um circuito RC simples, injete uma onda senoidal e analise o gráfico de atraso de fase.

```markdown
- [ ] Revisar operações com Números Complexos (Forma polar e retangular)
- [ ] Simular um circuito ceifador com diodo no LTspice ou Falstad
- [ ] Entender a diferença prática entre transistores BJT e MOSFET
```

---

### 💻 Semana 3: Engenharia de Software (O Salto do JS para o Nível Avançado)
*   **Programação Avançada:** Como o JavaScript tradicional esconde muito da Engenharia de Software pura, use esta semana para estudar os 4 pilares da **Programação Orientada a Objetos (POO)**: *Abstração, Encapsulamento, Herança e Polimorfismo* usando Classes do ES6+ no próprio JS.
    *   *📺 Curso Recomendado:* [Curso de POO - Canal Curso em Vídeo](https://youtube.com).
*   **Desenvolvimento Web I (Transição para TypeScript):** Em faculdades de engenharia, a matéria de Web costuma exigir tipagem rigorosa na correção das provas. Use essa semana para entender os fundamentos do **TypeScript** (Interfaces, Types e Generics).
*   **🎯 Desafio da Semana:** Pegar um componente pequeno de um projeto seu em **React (Vite + JS)** ou uma função utilitária de cálculo e tentar convertê-la manualmente para TypeScript para entender como as regras de tipagem previnem bugs em tempo de digitação.

```markdown
- [ ] Estudar Herança e Polimorfismo usando Classes no JavaScript
- [ ] Instalar o TypeScript globalmente (`npm install -g typescript`) e rodar os primeiros códigos de teste
- [ ] Instalar a extensão **Draw.io Integration** no VS Code e desenhar o diagrama UML de um sistema escolar (Aluno, Professor, Disciplina) antes de codificar
```

---

### 📐 Semana 4: Performance Vite, CAD e Consolidação
*   **Desenvolvimento Web I (Performance):** Estudar como o Vite faz o empacotamento (*bundle*) da sua aplicação React. Entender estratégias de renderização limpa e requisições assíncronas eficientes (Async/Await estruturado sem travar a thread).
*   **Ferramentas de Comp. Gráfica:** Configuração do ambiente CAD. O foco deve ser o aprendizado prático da sintaxe do terminal de comandos para precisão milimétrica.
    *   *🛠️ Software Recomendado:* [LibreCAD Oficial](https://librecad.org) (Software Livre, totalmente gratuito e extremamente leve).
*   **Gestão da TI:** Estudo conceitual sobre metodologias ágeis de desenvolvimento.
    *   *📚 Guia Prático:* Leia sobre a aplicação de frameworks como o [Scrum e Kanban pela Atlassian](https://atlassian.com).
*   **🎯 Desafio da Semana:** Abrir a ferramenta **Lighthouse** nativa do Google Chrome (F12 -> aba Lighthouse) em um app React seu que já esteja hospedado no ar. Analisar os gargalos reais de performance e aplicar otimizações no tamanho das importações de arquivos JavaScript.

```markdown
- [ ] Rodar o Lighthouse e anotar os pontos de melhoria do seu app React
- [ ] Desenhar um quadrado perfeito no LibreCAD usando apenas comandos de terminal (`@distancia<angulo`)
- [ ] Fazer uma revisão rápida de Integrais Duplas e Triplas (Cálculo III) no papel antes do recesso acabar
```
